# Custom Fonts Directory

Place your Halton font files here:
- `Halton-Regular.woff2` (or `.woff`, `.otf`, `.ttf`)
- `Halton-Medium.woff2`
- `Halton-SemiBold.woff2`
- `Halton-Bold.woff2`

The `@font-face` rules in `src/app/globals.css` are configured to automatically load these files or your system-installed Halton font.
